# Chimera

I maintain Chimera as my public monorepo of practical scripts and small automation tools.

I build most of these tools privately first, then promote the ones that are clean and reusable. I use this repository to show employers and collaborators the kind of automation work I enjoy: removing repetitive manual steps, organising files, simplifying workflows, and turning small ideas into useful tools.

## How I Organize It

I group scripts by language and task so the repository stays easy to browse:

- `Bash-and-Zsh` for shell helpers
- `PowerShell` for Windows and admin tasks
- `Python` for file, text, and workflow utilities
- `JavaScript` for browser and web automation
- `Lua` for Neovim-style editor helpers
- `GO` for command-line tools
- `VBA` for Office automation

## What I Publish

I only keep scripts here when I think they are ready to be judged in public.

That usually means the script:

- does not depend on my personal machine layout
- avoids secrets, credentials, and private data
- has a clear purpose and a predictable interface
- is general enough that another person could understand and adapt it

If something is still rough, personal, or experimental, I keep it in my private Chimera repo until I am happy with it.

## Python Highlights

The Python folder is where I keep a lot of my file and workflow automation work. It includes utilities for renaming files, sorting folders, generating quick reports, and other small jobs that save time in day-to-day work.

## Notes
