# Renaming

I keep bulk renaming utilities here.

These scripts help me clean up filenames across a directory tree when I need to remove characters, replace spaces, or make names more consistent before sharing or archiving files.

## Scripts

- `Mass_Rename.py` removes characters that are unsafe or awkward in filenames.
- `Replaces_Spaces_with_underscores.py` converts spaces in filenames to underscores.

Both scripts are designed to accept a folder path at runtime, which keeps them flexible and reusable across different projects.
