# Computer Tasks

This folder contains the Python scripts I use for practical file and folder work.

I built these utilities to save time on repetitive tasks such as renaming files, sorting directories, and cleaning up messy folder structures before sharing or archiving them.

## Subfolders

- `Renaming` for bulk filename cleanup and normalisation
- `File_Tidy` for grouping or moving files into a tidier structure

I keep these scripts small and direct so they are easy to understand, easy to adapt, and easy to explain in a portfolio context.
