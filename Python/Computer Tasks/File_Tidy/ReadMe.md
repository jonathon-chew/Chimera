# File Tidy

I use this folder for Python scripts that organise files and folders.

These utilities are aimed at small housekeeping jobs: moving files by extension, building folder structures automatically, and making large directories easier to browse.

## Subfolders

- `Compile_Files` for moving matching file types into a destination folder
- `Make_A_Folder_For_Every_File_Extention_And_Organise.py` for creating extension-based folders and sorting files into them
- `Picture_Tidy` for grouping photos into year, month, and day folders

The focus here is on practical automation rather than complex frameworks. I want these scripts to be simple enough that I can run them quickly and explain them clearly.
