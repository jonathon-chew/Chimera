# Picture Tidy

I use these scripts to organise photos into date-based folders.

The idea is to make a messy picture directory easier to browse by grouping files into year, month, and day folders based on their timestamp metadata.

## Scripts

- `Mac_Tidy.py` uses file creation time on macOS.
- `Windows_Tidy.py` uses file timestamps on Windows.

I keep separate versions because the metadata calls differ between operating systems, but the goal is the same in both cases: turn an unstructured photo folder into something easier to manage.
