# Compile Files

I use this script to collect files with a chosen extension and move them into a destination folder.

It walks a directory tree, checks each file extension, and moves matching files into a folder I provide at runtime.

## Script

- `Compile_Files.py` prompts for:
  - the source folder
  - the target extension
  - the destination folder

This is the kind of utility I build when I want a quick, repeatable way to gather one file type without manually sorting through a directory tree.
